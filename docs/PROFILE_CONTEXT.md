# Profile Context

## Purpose

Este documento recoge el contexto profesional real de Alba para alimentar textos, datos locales y decisiones de contenido del portfolio.

Debe leerse junto con:

- `AGENTS.md`
- `docs/visual/VISUAL_REFERENCE.md`

Su objetivo es ayudar a Codex y futuros agentes IA a actualizar el contenido del portfolio con coherencia, sin inventar datos, sin añadir información sensible y manteniendo un posicionamiento profesional.

- Evolución técnica.

- Perfil Full Stack.

- Producto.
